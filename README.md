## Infos clés du site actuel

- Association loi 1901

- Organise des ateliers de sensibilisation au handicap (écoles, centres de loisirs, entreprises)
- Ateliers : basket fauteuil, parcours fauteuil, parcours aveugles, torball, boccia
- Financement par contributions + partenaires
- Tarifs avantageux pour les adhérents handicapés
